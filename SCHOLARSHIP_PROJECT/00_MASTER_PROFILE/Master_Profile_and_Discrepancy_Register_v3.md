# Evidence scale (your definitions)

| Code | Meaning |
|---|---|
| **E0** | Information from your supplied documents |
| **E1** | Verified directly with an official institution or employer source |
| **E2** | Official-source search result requiring direct verification |
| **E3** | Secondary source |
| **E4** | Your personal confirmation |
| **E5** | Unsupported or contradictory information. **Never used in a final application** |

**Rule:** E4 does not replace mandatory documentary evidence. A field becomes **FINAL** only with E0/E1 evidence (plus E4 where the document is silent).

**Privacy:** no passport number, ID number, date of birth, phone or personal e-mail is recorded in this file.
