## 4. Evidence that would most strengthen the application (in order)

1. **Employer experience letters** with titles, dates and duties (SantimPay, Kifiya). These are mandatory for credibility.
2. **A manager reference** describing one concrete contribution.
3. **The final-project report or abstract** (your strongest academic evidence).
4. **A public portfolio:** 2–3 clean repositories, for example an Ansible role, a CI pipeline and a monitoring stack, built from scratch so no employer code is exposed.
5. **A current certification with an ID:** CKA renewal, or an AWS/Azure associate exam (optional; costs money and time).
6. **Registrar class-rank letter**, only if it is favourable.
